# Toshkent tramvayi: 22 vagon, 1901–2016

Toshkent ko'chalarida 1901-yildan 2016-yilgacha yurgan tramvay vagonlarining interaktiv 3D galereyasi. Har bir vagonni aylantirib ko'rish, qachon kelgani va shahar uchun nimani o'zgartirganini o'qish mumkin.

Loyiha «Toshkent tramvayi» hujjatli filmi uchun yig'ilgan materiallar asosida tayyorlangan. Muallif: Iskandar Soliyev, Archemistry Urban.

- `index.html` — sahifa ([model-viewer](https://modelviewer.dev) bilan)
- `models/` — vagonlarning GLB modellari (meshopt, WebP tekstura)
- `kartochkalar/` — har bir vagon turining kartochkasi (1600×1000)

**Eslatma.** Modellar arxiv suratlari asosidagi vizual rekonstruksiya, o'lchov chizmasi emas. Ranglar va ba'zi tafsilotlar taxminiy. Manbalar sahifaning o'zida, «Manbalar va modellar haqida» bo'limida.
